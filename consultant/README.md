# 医信顾问（MedIT Advisor）

医疗行业信息化咨询专家：从医院信息化规划、系统集成、数据治理与互联互通，到 AI+医疗落地与实施运维，提供全链路咨询建议。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 医院信息化整体规划与 HIS/EMR/LIS/PACS 核心系统选型、集成与升级路径
- 数据治理、互联互通标准化成熟度测评与电子病历分级评价准备
- AI+医疗落地评估：医疗大模型、智能问诊、临床辅助决策的可行性与部署方案
- 选型与架构评估：模型能力、开发方式（自研/合作/采购）、供应商性价比、私有云/公有云/混合云架构
- 实施运维与维保咨询：项目管理、传统维保与 AI FDE 交付模式对比、故障响应体系
- **可信数据空间**：跨机构数据协作（多中心科研、专病队列、区域慢病、医保-医疗协同）的「数据不出域、可用不可见」方案；使用控制、隐私计算（联邦学习/MPC/TEE）、身份可信、全程审计、价值分配五要素；先定数据权属契约再谈技术
- **三医融合**：医疗-医保-医药协同（DRG/DIP 支付改革、集采、价格联动）对系统的要求；病案首页/结算清单/分组器口径一致性诊断；病种成本与防诊疗变形监控
- **信创可信**：信创国产化替代路线（先外围后核心、数据库兼容层、双轨并行、可回退）；等保 2.0、密评（国密 SM2/SM3/SM4）、数据分类分级；信创与可信分列不互替

方法论底座见仓库 [`knowledge/三大扩展方向-方法论底座.md`](../knowledge/三大扩展方向-方法论底座.md)。

## 使用示例

- 我们医院想升级现有HIS系统，现有系统老旧且数据分散，请帮我做一份信息化规划建议。
- 医疗数据互联互通标准化成熟度测评应该怎么准备？
- 医院计划落地AI辅助诊断，应该选私有云还是公有云部署？
- 我们要做跨院科研协作，怎么建可信数据空间做到数据不出域、可用不可见？
- DRG/DIP 支付改革下，病案首页和医保结算清单口径不一致该怎么治理？
- 核心HIS/EMR系统信创替换该怎么排顺序，同时满足等保和密评要求？

## 安装

将专家包目录放到专家目录下：

```
/Users/pine/.workbuddy/plugins/marketplaces/my-experts/plugins/medical-it-consultant/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
